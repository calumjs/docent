Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, the README — and writes a small site that explains what the project is, what's been shipping, and what's open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates itself on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team with a project that deserves a better introduction than a README. Docent is useful when people show up from search or a link and want a plain-English answer to "what is this and should I care" — and currently get a wall of markdown.

The typical use: a developer tool, library, or side project that's public on GitHub but has no web presence. Adding Docent takes two commands and one conversation; from there the site maintains itself.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far — for visitors who might never read the code.

## How it works

Docent is a Claude Code plugin. Two install commands add the skill to any Claude Code session. One conversation sets it up: the skill asks about tone and cadence, analyzes the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. Each run checks whether the status page, overview, or changelog is stale, decides whether there's enough recent activity to write a journal post, and produces a PR with whatever combination makes sense. Nothing goes live without a pull request.

The generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; the Astro template is yours.

## Getting started

In any Claude Code session inside your target repo, run:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

See the [README](https://github.com/calumjs/docent) for the full install steps and post-merge setup, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full design.
