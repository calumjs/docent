Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site that explains what the project is, what has been shipping, and what is open. The site lives in `/docs` inside the same repo and deploys to GitHub Pages.

## Who it's for

A solo maintainer or small team with a project that deserves a clearer introduction than a README. Docent is useful when visitors arrive from search or a shared link and want a human-readable answer to "what is this and should I care?"

It is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, and the story so far — for visitors who might never read the code.

## What it produces

A live site at `username.github.io/project` with five pages:

- **Overview** — an explanation of what the project is and who it is for, generated from the README
- **Journal** — posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized, with known bugs and in-progress work called out
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab
- **Changelog** — human-readable release notes derived from tags and merged PRs

No hosted service, no API keys, no backend. Content generation runs through your Claude Code subscription. Forms submit by opening pre-filled GitHub issues.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any Claude Code session. One conversation sets up the site: the skill asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR is merged, a daily Routine keeps the site current. Each morning the Routine checks what has drifted — the README, open issues, new tags — and decides whether to refresh the content, write a journal post, both, or nothing. Nothing goes live without a pull request.

You can also invoke Docent manually: "Docent, write a journal post about the auth refactor."

## Getting started

In any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say:

> **set up Docent for this repo**

The skill walks through the rest. See the [README](https://github.com/calumjs/docent) for the full steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
