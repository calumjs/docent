Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, the README — and produces a site that answers the visitor's question: what is this and should I care? The site lives in `/docs`, deploys to GitHub Pages, and updates on a schedule through a Claude Code Routine.

## Who it's for

A maintainer or small team with a project that attracts outside interest but no dedicated documentation site. If visitors currently land on your README and have to piece together what the project does, Docent is for you.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those tools describe how a library works. Docent describes what a project *is*: a plain-English introduction, a summary of open issues, a journal of recent activity, and a changelog — all derived from the repo itself.

## How it works

Two install commands add the skill to any Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a single daily Routine keeps things current. The Routine decides for itself whether to refresh the status page, write a journal post, both, or nothing — based on what has happened since the last run. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** — scaffolds `/docs` and writes the first content.
- **`update`** — refreshes content as issues and the README change.
- **`digest`** — writes a journal post summarizing recent activity.
- **`release`** — turns a new tag into a changelog entry.
- **`triage`** — drafts suggestions for new issues without touching them.

Generated content lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the plugin from any Claude Code session inside your target repo, then say **"set up Docent for this repo."** The skill walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps.
