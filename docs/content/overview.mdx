Docent turns a GitHub repository into a public-facing static website. It reads your commits, issues, releases, and README, then generates a small site that tells your project's story to visitors who may never read the code. The site lives in `/docs`, deploys to GitHub Pages, and updates itself on a daily schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team with a project that deserves a clearer introduction than a README. If people arrive from a link or search result and you want them to get a quick, honest answer to "what is this and should I care?" — without handing them a wall of markdown — Docent is the tool for that.

Docent is not a documentation framework. It doesn't replace Docusaurus or MkDocs. Those tools describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far — for visitors who need the overview, not the reference.

## How it works

Two install commands bring the skill into any Claude Code session. From there, one conversation sets up the site: Docent reads the repo for design signals, picks a visual style, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. Each morning it checks what has drifted — status page, overview, changelog — decides whether recent activity adds up to a journal post worth reading, and opens a PR containing whatever combination makes sense. Nothing goes live without a pull request.

Five modes cover the full operation:

- **`init`** — scaffolds the `/docs` site and generates the first content.
- **`update`** — refreshes the status page and overview as issues and the README evolve.
- **`digest`** — writes a journal post summarizing recent activity.
- **`release`** — turns a new tag into a changelog entry.
- **`triage`** — drafts suggestions for incoming issues, without touching them automatically.

The generated content — overview, journal posts, status summaries, changelog entries — lives in `/docs/content/` as structured MDX and JSON. An Astro site template in `/docs/src/` renders it. Content and presentation are owned separately: Docent writes the first; you own the second.

## Getting started

Install the plugin into any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say **"set up Docent for this repo."** See the [README](https://github.com/calumjs/docent) for full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
