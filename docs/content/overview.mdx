Docent turns a GitHub repository into a public-facing static website. Two install commands bring the skill into any Claude Code session; from there, one conversation scaffolds a site, generates the first content, and opens a pull request. After that, a daily Routine keeps the site current without further manual work.

## Who it's for

A maintainer who wants visitors — people who arrived from a blog post, a link, or a search result — to get a useful answer to "what is this and should I care?" instead of a wall of markdown. Docent is not a replacement for API-documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far.

A solo developer with a weekend project is a good fit. So is a small team shipping a tool that has users outside the contributor group. Projects that document themselves primarily through a README and a busy issue tracker tend to benefit the most.

## What the site includes

Docent produces five sections:

- **Overview** — an AI-written explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity, written on a configurable cadence
- **Status** — open issues grouped and summarized, surfaced as a human-readable page
- **Changelog** — release notes derived from version tags and merged pull requests
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab

The site lives in `/docs` inside the same repository and deploys to GitHub Pages. No hosted service, no API keys, no backend. Content generation runs through your Claude Code subscription; a daily Routine handles the updates.

## How it works

Install Docent into a Claude Code session with two commands, then say "set up Docent for this repo." The skill runs its `init` procedure: it asks about tone, cadence, and whether to use a custom domain; reads the repository for design signals; scaffolds an Astro site under `/docs` from a bundled template; generates the initial content; and opens a pull request against the default branch.

After merging, enable GitHub Pages with Actions as the source, then schedule the daily Routine. The Routine runs `update` mode each morning: it checks whether the status page, overview, or changelog have drifted, decides whether there is enough activity to write a journal post, and produces a pull request with whatever combination makes sense — or nothing, if the site is already current.

Docent can also be invoked on demand: "write a journal post about the auth refactor," "generate release notes for v1.2.0," "triage the new issues."

## Getting started

Install the skill into a Claude Code session inside your target repository, then say:

```
set up Docent for this repo
```

The `init` procedure walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps and the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design rationale.
