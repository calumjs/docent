Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website — and keeps it current automatically. It reads your commits, issues, releases, and README, then generates a small site that answers the visitor's first question: "What is this, and should I care?"

## Who it's for

A solo developer or small team with a project that deserves a better introduction than a wall of markdown. If people land on your GitHub page, squint at the README, and leave without understanding whether the project is for them — Docent solves that.

Docent is not a documentation platform in the Docusaurus or MkDocs sense. Those tools help contributors understand how a library works. Docent helps visitors understand what a project *is*: the pitch, the recent story, what's broken, what's coming.

## What it produces

A live site at `username.github.io/project` — no backend, no hosted service, no API keys beyond your Claude Code subscription — with:

- **Overview** — a plain-language explanation of what the project does and who it's for
- **Journal** — blog posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized: known bugs, in-progress work, feature requests
- **Changelog** — release notes derived from git tags and merged PRs
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab

## How it works

Two install commands add Docent to your Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, one Routine keeps the site current:

```
/schedule Docent update daily at 08:00 — prompt: "Docent: run update mode."
```

The Routine is adaptive — it decides each morning whether to refresh the status page, write a journal post, both, or nothing, based on what's happened in the repo since the last run. Everything goes through a pull request; nothing publishes without review.

You can also invoke Docent by hand: "Docent, write a journal post about the auth refactor."

## Getting started

Install the skill into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
