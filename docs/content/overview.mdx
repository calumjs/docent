Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, then produces content explaining what the project is, what has shipped, and what is open. The site lives under `/docs`, deploys to GitHub Pages, and updates itself on a schedule through a Claude Code Routine.

## Who it's for

A solo maintainer or small team whose project deserves more than a README for first-time visitors. When someone finds a project through a link or search result and wants to know whether to pay attention, a README written for contributors is the wrong document. Docent produces the right one: an overview aimed at newcomers, a running journal of recent activity, and a status page showing what is broken or in flight.

Docent is not an API documentation tool. It does not generate function references, type signatures, or usage examples. Tools like Docusaurus and MkDocs serve contributors who have already decided to use a project. Docent serves visitors who have not decided yet.

## How it works

Docent is a Claude Code plugin. Two commands install it into any Claude Code session. From there, a single conversation sets up the site: Docent asks about tone and update cadence, reads the repo for design signals, scaffolds an Astro project under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, a single daily Routine keeps the site current. Each run checks whether the README, issues, or tag list have changed since the last run, decides whether enough has happened to write a journal post, and produces a PR containing whatever combination is warranted — or nothing at all if everything is already up to date.

Docent has five modes:

- **`init`** — scaffolds `/docs` and generates the first content
- **`update`** — refreshes the overview, status, and changelog as sources change; writes journal posts when there is enough to say
- **`digest`** — writes a journal post on demand ("Docent, write a post about the auth refactor")
- **`release`** — turns a tagged release into a changelog entry
- **`triage`** — drafts suggestions for new issues without touching them automatically

Generated content lives in `/docs/content/` as MDX and JSON. The Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the plugin in any Claude Code session inside your repo, then say "set up Docent for this repo." The skill handles the rest. See the [README](https://github.com/calumjs/docent) for the two install commands and the post-merge steps.
