Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, and produces a site that explains what the project is, what has been shipping, and what is open — for visitors who arrive from search or a shared link and want a human-readable answer to "what is this."

## Who it's for

A solo maintainer or small team whose project has visitors: people who found the repo from outside and want to understand it without reading the code. Docent is not a replacement for API documentation tools like Docusaurus or MkDocs, which describe how a library works. Docent describes what a project *is* — the pitch, the current state, the story so far.

If your project gets external interest but your front door is still a wall of markdown, Docent is the gap it fills.

## What it produces

A static site at `username.github.io/project`, deployed from the repo itself to GitHub Pages. No hosted service, no API keys, no backend. The site has five sections:

- **Overview** — an explanation of the project written from the README and repo context.
- **Journal** — posts summarizing recent activity, written on a cadence you configure.
- **Status** — open issues grouped and summarized, updated as the issue tracker changes.
- **Changelog** — release notes derived from tags and merged PRs.
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Say "set up Docent for this repo" and the skill runs its init procedure: asks about tone, cadence, and domain; scaffolds an Astro site under `/docs`; generates the first round of content; and opens a pull request. After merging, you enable GitHub Pages and set up a Routine:

```
/schedule Docent update daily at 08:00 — prompt: "Docent: run update mode."
```

The Routine runs on a schedule. It checks whether the status page is stale, whether the overview needs a refresh, and whether enough has happened to write a journal post. It produces a PR containing whatever combination makes sense — content refresh, new journal post, both, or nothing. Inference runs through your Claude Code subscription; no additional credentials are required.

You can also invoke Docent by hand: "Docent, write a journal post about the auth refactor."
