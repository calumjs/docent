Docent turns a GitHub repository into a public-facing static website. It reads
your commits, issues, releases, and README, then generates a small site that
tells visitors what the project is, what has been shipping, and what is open.
The site lives in `/docs` inside the same repository, deploys to GitHub Pages,
and updates on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team with a project that deserves a better first
impression than a wall of markdown. Docent is most useful when people arrive
from a search result or a link and want a clear answer to "what is this and
should I care" — not a reference manual.

It is not a replacement for API documentation tools like Docusaurus or MkDocs.
Those describe how a library works. Docent describes what a project *is*: the
pitch, the current state, the story so far. If a visitor might never read your
code, Docent is the page they will read instead.

## How it works

Two install commands bring the skill into any Claude Code session. One
conversation handles setup: Docent asks about tone and cadence, reads the
repository for design signals, scaffolds an Astro site under `/docs`, generates
the initial content, and opens a pull request against your default branch.

After merging, a single daily Routine keeps the site current. It decides for
itself whether to refresh the status page, write a journal post, or both —
based on what has happened in the repository since the last run. Nothing goes
live without a pull request.

Docent has five modes:

- **`init`** scaffolds the site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside
your target repository, run:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **"set up Docent for this repo"**

See the [README](https://github.com/calumjs/docent) for the full install steps
and post-merge configuration, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md)
for the full design.
