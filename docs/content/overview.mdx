Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, and writes a small site that explains what the project is, what has shipped, and what's open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and keeps itself current through a daily Routine that runs on a schedule.

## Who it's for

A solo maintainer or a small team with a project that deserves a human-readable introduction beyond a README. Docent is useful when visitors arrive from search, a blog post, or a shared link and want a quick answer to "what is this and should I care" — and currently get a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far — for visitors who might never read the code.

## What it produces

A live site at `username.github.io/project` with five sections:

- **Overview** — an AI-written explanation of what the project does and who it's for.
- **Journal** — posts summarizing recent activity on a configurable cadence.
- **Status** — open issues grouped and summarized, with bugs and in-progress work called out separately.
- **Changelog** — release notes derived from tags and merged PRs.
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab.

## How it works

Two install commands bring the skill into any Claude Code session. From there, one conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. The Routine decides on each run whether to refresh the status page, write a journal post, both, or nothing — based on what's happened in the repo since the last run. Nothing goes live without a pull request.

Docent has five modes, each a procedure the skill runs when you ask for it:

- **`init`** scaffolds the site and writes the first content.
- **`update`** refreshes status and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without modifying them.

The generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the plugin into any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**. See the [README](https://github.com/calumjs/docent) for the full steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
