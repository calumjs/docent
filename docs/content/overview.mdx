Docent turns a GitHub repository into a public-facing static website. It reads the repository — commits, issues, releases, the README — and produces a site that explains what the project is, what has been happening, and what is open. The site lives in `/docs` inside the same repository, deploys to GitHub Pages, and keeps itself current through a scheduled Claude Code Routine.

## Who it's for

A solo maintainer or a small team with a project that merits a better public introduction than a README. The typical situation: someone finds the project through a link or a search result and lands on a wall of markdown. They want a plain-language answer to "what is this and should I care" — and the README wasn't written for them.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story of what has shipped — for visitors who may never read the code.

## How it works

Two install commands bring the skill into any Claude Code session. From there, a single conversation does the setup: Docent reads the repository for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. Each run checks what's stale and decides whether to refresh the status page, write a journal post, or both — based on what's changed in the repository since the last run. Nothing goes live without a pull request.

Docent has five modes:

- `init` scaffolds the site and writes the first content.
- `update` refreshes the overview, status page, and changelog as the repository changes.
- `digest` writes a journal post summarizing recent activity.
- `release` converts a new tag into a changelog entry.
- `triage` drafts suggestions for new issues, without modifying them.

Generated content — overview, journal posts, status summaries, changelog entries — lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the skill in your repository, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps.
