Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, and produces a site that explains what the project is, what has been happening, and what's open — written for visitors who want a human-readable entry point, not a code tour.

## Who it's for

A solo maintainer or small team that wants something better than a README as a first impression. When someone arrives from a search result or a link and asks "what is this and should I care," a README answers with installation instructions. Docent answers with a brief explanation, recent news, and open issues.

Docent is not an API documentation tool. It doesn't describe function signatures or module hierarchies. It describes what a project *is*: the purpose, the current state, the recent story — for visitors who may never touch the code.

## How it works

Docent installs as a Claude Code plugin. Two commands add it to any Claude Code session, and a single conversation sets the site up: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. No hosted service, no API keys, no backend.

After the PR merges, a daily Routine keeps the site current. Each run checks what has changed since the last update, decides whether to refresh the status page, write a journal post, or both, and opens a new PR with any changes. The decision adapts to what has actually happened — a quiet week produces nothing; a week with a release and several issues closed produces a post.

The site includes:

- **Overview** — this page: an AI-written introduction to the project.
- **Journal** — posts summarizing recent activity on a configurable cadence.
- **Status** — open issues grouped and summarized by type.
- **Changelog** — human-readable release notes derived from tags and merged PRs.
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues.

## Getting started

Install the plugin into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent runs the rest. See the [README](https://github.com/calumjs/docent) for install steps and the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
