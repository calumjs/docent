Docent turns a GitHub repository into a public-facing static website, kept current by a daily routine. It reads the repo's commits, issues, releases, and README, then writes a small site that explains what the project is, what's been shipping, and what's open. The site lives under `/docs` inside your repository and deploys to GitHub Pages. No hosted service, no API keys, no backend required.

## Who it's for

A solo maintainer or small team with a project that deserves a better introduction than a README. The typical visitor Docent serves is someone who arrived from a search result or a link and wants a quick answer to "what is this, and should I care" — not a full API reference.

Documentation tools like Docusaurus and MkDocs describe how a library works. Docent describes what a project *is*: the pitch, the current state, the recent story. The two aren't substitutes.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any Claude Code session. One conversation runs the setup: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the first content, and opens a pull request.

After the PR merges, a daily Routine keeps things current. Each morning it checks which content anchors have drifted — open issues changed, README updated, new release tags — and produces a PR with whatever combination makes sense: a status refresh, a new journal post, both, or nothing. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** — sets up the site and writes the first content
- **`update`** — refreshes the overview, status, and changelog as things change
- **`digest`** — writes a journal post summarizing recent activity
- **`release`** — turns a new tag into a changelog entry
- **`triage`** — drafts suggestions for new issues

Generated content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; the presentation layer is yours.

## Getting started

Two commands in any Claude Code session inside your target repo, then: "set up Docent for this repo." See the [README](https://github.com/calumjs/docent) for the full install steps and the two post-merge actions (enabling GitHub Pages and scheduling the daily Routine).
