Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site that explains what the project is, what has been shipping, and what is open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates itself on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or a small team whose project deserves a better introduction than a README. Docent is useful when visitors arrive from a search result or a link and want a plain-language answer to "what is this and should I care" — and currently get raw markdown.

Docent is not a documentation tool in the Docusaurus or MkDocs sense. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far. Its audience is visitors who may never read the code.

## How it works

Two install commands bring the skill into any Claude Code session. From there, one conversation sets up the site. Docent reads the repo for design signals, picks a visual style, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. No hosted service, no API keys, no backend.

After merging, one daily Routine keeps the site current. The Routine checks what is stale — the status page, the overview, the changelog — and decides whether to write a journal post summarizing recent activity. Whatever it produces goes into a PR, not directly to the branch.

Docent has five modes:

- **`init`** scaffolds the site and writes the first content.
- **`update`** refreshes the overview and status as the README and issues change.
- **`digest`** writes a journal post summarizing a period of activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues without modifying them.

The generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; the presentation layer is yours to own.

## Getting started

Install the skill from Claude Code:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say "set up Docent for this repo." Docent walks through the rest. See the [README on GitHub](https://github.com/calumjs/docent) for full install steps.
