Docent is a Claude Code plugin that reads a GitHub repo — its commits, issues,
releases, and README — and produces a static website that explains the project
to visitors who may never read the code. The site deploys to GitHub Pages from
a `/docs` folder in the same repo. No hosted service, no API keys, no
additional backend is required.

## Who it's for

A maintainer or small team whose project deserves a clearer public face than
a README provides. Docent is most useful when visitors arrive from a link or
search result and need a quick answer to "what is this and should I care" —
and what they find today is a dense markdown file aimed at contributors.

Docent is not a substitute for API reference tools like Docusaurus or MkDocs.
Those describe how a library works in detail. Docent describes what a project
*is*: the pitch, the current status, the recent activity — for people deciding
whether to use it or follow it.

## What it produces

After setup, Docent generates and maintains five sections:

- **Overview** — an explanation of what the project is and who it's for (this page)
- **Journal** — posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized, updated on each run
- **Changelog** — release notes derived from tags and merged pull requests
- **Bug report / Feature request** — forms that open pre-filled GitHub issues

All content lives in `/docs/content/` as structured MDX and JSON. An Astro
template in `/docs/src/` renders it. Docent owns the content files; you own
the presentation layer.

## How it works

Install Docent into a Claude Code session with two commands:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say **"set up Docent for this repo."** The skill's `init` procedure
takes it from there: it asks about tone and cadence, reads the repo for
design signals, scaffolds the Astro site, generates the initial content, and
opens a pull request. After merging, two manual steps complete the setup —
enabling GitHub Pages and scheduling a daily Routine. The Routine runs on
your Claude Code subscription tokens and decides for itself whether to refresh
content, write a journal post, or do nothing — based on what's changed since
the last run. Nothing goes live without a pull request.

Docent also responds to on-demand requests: **"write a journal post about the
auth refactor"** or **"generate release notes for v2.1"** invoke the relevant
mode directly.
