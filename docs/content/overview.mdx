Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, then generates a small site that tells visitors what the project is, what's been shipping, and what's currently open.

## Who it's for

A solo maintainer or small team who wants a better first impression than a wall of markdown. When someone arrives from a search result or a shared link, the README typically gives them install commands first and an explanation second — or never. Docent puts the explanation first: what the project is, who it helps, and what's happening in it right now.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is* and whether it's worth digging into — for visitors who might never open a code editor.

## How it works

Two install commands add the skill to any Claude Code session. From there, one conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request.

After the PR merges, a daily Routine keeps the site current. The Routine decides whether to refresh the status page, write a journal post, or both — based on what's actually happened in the repo since the last run. Nothing is published without a pull request.

Docent has five modes:

- **`init`** scaffolds `/docs` and generates the first content.
- **`update`** refreshes content as issues change and the README evolves.
- **`digest`** writes a journal post on demand — "write a post about the refactor."
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts notes on new issues, without filing or closing anything automatically.

Generated content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content, you own the presentation.

## Getting started

Install the skill into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design details.
