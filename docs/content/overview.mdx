Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, and writes a site that tells the project's story to visitors who may never read the code.

The site lives inside the same repository under `/docs` and deploys to GitHub Pages. There is no hosted service, no API keys, and no backend. Content updates run through a Claude Code Routine on your existing subscription — nothing extra to pay for, nothing extra to configure.

## Who it's for

Docent is for maintainers who want a better answer to "what is this project?" than a wall of markdown. It helps when:

- People arrive at your repo from a search result or a link and need a human-readable introduction
- You want a status page that shows open issues without asking visitors to navigate GitHub
- You want release notes that read like writing, not a raw commit list

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far. It is aimed at the curious visitor, not the existing contributor.

## How it works

Two install commands bring the skill into any Claude Code session. One conversation sets up the site. Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, a daily Routine keeps the site current. Each morning it checks what has changed — open issues, the README, new release tags — and decides whether to refresh the status page, write a journal post, or both. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the site and writes the first content.
- **`update`** refreshes status and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

The content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the skill, then open Claude Code in your target repo and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
