Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, then writes a small site that tells visitors what the project is, what has been shipping, and what is open.

The site lives in `/docs` inside the repository and deploys to GitHub Pages. No hosted service, no API keys, no backend. Content stays current through a Claude Code Routine — a scheduled prompt that runs daily, decides whether to refresh the status page, write a journal post, or both, and opens a pull request with whatever it produced.

## Who it's for

A solo maintainer or small team whose project gets visitors from search, a link, or a mention — people who want a quick answer to "what is this and should I care," and currently get a README.

Docent is not a replacement for API documentation. Tools like Docusaurus or MkDocs describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story of what has shipped. For visitors who might never read the source.

## What it produces

Two install commands and one conversation with Claude Code scaffold a site under `/docs`. From there, each page updates itself on a schedule:

- **Overview** — an AI-written explanation of the project, refreshed when the README drifts or more than 90 days have passed.
- **Journal** — posts summarizing recent activity, written when there is enough to say. Honest silence beats padded prose.
- **Status** — open issues, grouped and summarized, updated whenever the issue set changes.
- **Changelog** — human-readable release notes derived from tags and merged PRs.
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab.

Generated content lives in `/docs/content/` as MDX and JSON. An Astro template renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say **"set up Docent for this repo."** The skill handles the rest: scaffolds the site, generates the first content, and opens a pull request. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
