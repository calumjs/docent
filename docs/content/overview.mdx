Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site that tells non-contributor visitors what the project is, what has been shipping, and what is currently open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates itself on a schedule through Claude Code Routines.

## What you get

After running init, the site has five sections:

- **Overview** — a prose explanation of what the project does and who it is for, derived from the README and repo structure.
- **Journal** — dated posts summarizing recent activity. Written on a configurable cadence (weekly by default) or on demand.
- **Status** — open issues grouped by kind: bugs, in-progress work, feature requests. Regenerated whenever the issue set changes.
- **Changelog** — human-readable release notes built from git tags and the commits between them.
- **Bug reports / Feature requests** — forms that open pre-filled GitHub issues in a new tab. No backend required.

## Who it's for

A solo maintainer or a small team with a project that deserves more than a README as its public face. Docent is useful when someone arrives from a search result or a shared link and wants to know "what is this and should I care" — and currently gets a wall of markdown.

It is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current state, and the story so far — for visitors who may never read the code.

## How it works

Two install commands bring Docent into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say "set up Docent for this repo." Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After merging, you enable GitHub Pages once (via `gh api` or the repo's Settings UI) and schedule the daily Routine that keeps the site current:

```
/schedule Docent update daily at 08:00 — prompt: "Docent: run update mode."
```

The Routine runs through your Claude Code subscription — no separate API key required. Each morning it checks what has drifted, decides whether the activity warrants a journal post, and opens a PR with whatever combination makes sense: content refresh, new journal post, both, or nothing.
