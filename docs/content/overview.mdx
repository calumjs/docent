Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, and produces a site that describes what the project is, what has been shipping, and what is open. The site lives in `/docs` inside the repository, deploys to GitHub Pages, and updates itself on a schedule through a Claude Code Routine.

## Who it's for

A solo maintainer or small team with a project that deserves a better introduction than a README. When visitors arrive from a link or search result, the README answers "how do I use this" — Docent answers "what is this and should I care."

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far. The audience is a curious visitor who may never read the code.

It is particularly useful for projects that ship changes regularly and want those changes visible to an audience that does not follow the commit log.

## What it produces

A live site at `username.github.io/project` with five sections:

- **Overview** — an AI-written explanation of what the project is and who it's for, derived from the README and repo structure.
- **Journal** — posts summarizing recent activity, written on a configurable cadence.
- **Status** — open issues grouped and summarized, with known bugs and in-progress work surfaced clearly.
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab. No backend required.
- **Changelog** — human-readable release notes derived from tags and merged PRs.

All content is generated by Claude and committed to the repository. GitHub Pages builds and publishes the site on each merge. No hosted service, no API keys, no backend infrastructure.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside the target repository:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then tell Claude: **set up Docent for this repo**

The skill asks about tone, cadence, and custom domain; analyzes the repo for design signals; scaffolds `/docs` from a bundled Astro template; and opens a pull request. After merging, two steps enable GitHub Pages and configure the daily Routine that keeps content fresh.

[See the README for the complete setup sequence](https://github.com/calumjs/docent#readme) and `SPEC.md` for the full technical design.
