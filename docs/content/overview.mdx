Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads commits, issues, and releases, and writes a site that explains what the project is to visitors who might never open the code.

## Who it is for

Most repos have a README. Few have a site a non-developer can land on and leave with a clear picture of what the project does, what is being worked on, and how to get involved. Docent fills that gap without a separate CMS, a hosted service, or manual content work.

If you have ever sent someone a GitHub link and watched them bounce off the README, Docent is for that. It produces a site at `username.github.io/project` with five sections: an AI-written overview of the project, a journal of recent activity, a grouped summary of open issues, human-readable release notes, and forms that open pre-filled GitHub issues for bug reports and feature requests.

The site lives in your repo under `/docs` and deploys to GitHub Pages. No hosted service, no API keys, no backend. Inference runs through your Claude Code subscription on a Routine.

## How it works

Docent is a skill — a set of instructions that runs inside a Claude Code session. After a two-command install, saying "set up Docent for this repo" starts the init process: it asks about tone and update cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily or weekly Routine keeps the site current. The Routine decides on each run whether to refresh the status page, write a journal post, generate new changelog entries, or do nothing — based on what has happened since the last run. Everything goes through pull requests; nothing pushes directly to the default branch.

The generated content — overview text, journal posts, status summaries, changelog entries — lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Two install commands bring the skill into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then tell Claude to set up Docent for the repo. See the [README](https://github.com/calumjs/docent) for the full setup steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
