Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site that tells your project's story to visitors who aren't already contributors.

## Who it's for

A solo maintainer or small team with a project that deserves a clearer introduction than a README. Docent is most useful when visitors arrive from a link or a search result and want a plain answer to "what is this and should I care" — and currently get a wall of markdown.

It's not a substitute for API documentation tools like Docusaurus or MkDocs. Those describe how a library works; Docent describes what a project *is*: the pitch, the current status, the story so far.

## How it works

Two install commands bring Docent into any Claude Code session. A single conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. Update mode runs on a schedule and decides on its own whether to refresh the status page, write a journal post, or both — based on what's happened in the repo since the last run. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the `/docs` site and generates the first content.
- **`update`** refreshes overview, status, and changelog as things change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

Content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install from any Claude Code session inside your target repo and say "set up Docent for this repo." Docent walks through the rest. The [README](https://github.com/calumjs/docent) has the full install steps; the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) has the design.
