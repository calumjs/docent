Docent is a Claude Code plugin that reads a GitHub repository and writes a public-facing website for it. The site lives in `/docs`, deploys to GitHub Pages, and updates itself on a schedule — no hosted backend, no API keys, no separate service.

## Who it's for

A maintainer with a project that deserves a better explanation than a README. When someone arrives from a search result or a shared link, they want to know whether the project is worth their attention — not wade through installation instructions to find out. Docent produces that front door: an overview of what the project is, a status summary of what's open and in progress, a journal of what's been shipping, and a changelog of what's been released.

Docent is not an API documentation tool. Docusaurus and MkDocs describe how a library works at the level of functions and modules. Docent describes what a project *is* — the pitch, the current state, the story so far — for visitors who may never read the source.

## How it works

Two commands install Docent as a Claude Code plugin. From there, one conversation handles setup: Docent asks a few questions about tone and cadence, analyzes the repo for design signals, generates initial content, and opens a pull request.

After merging that PR, a daily Routine keeps the site current. Each run checks what's stale — issues changed, README updated, enough PRs merged for a journal post — and produces a PR containing whatever makes sense. Some days that's a status refresh; some days it's a journal post; some days it's both; some days it's nothing. The decision is made by the Routine, not by you. Nothing goes live without a pull request.

Docent has five modes: `init` scaffolds the site from scratch; `update` refreshes content on a daily schedule; `digest` writes a journal post on demand; `release` converts a tagged release into a changelog entry; `triage` drafts suggestions for new issues without modifying them.

## Getting started

Install the plugin, then open Claude Code and say "set up Docent for this repo." The init flow handles the rest. See the [README](https://github.com/calumjs/docent) for the install commands and a full walkthrough of what happens after.
