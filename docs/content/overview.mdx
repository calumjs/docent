Docent turns a GitHub repository into a public-facing static website. It reads your repo — commits, issues, releases, and the README — and writes a site that tells your project's story to visitors who might never open the code.

## Who it's for

A solo maintainer or small team with a project that deserves a clearer introduction than a README provides. When someone arrives from a search result or a shared link and asks "what is this and should I care," the README is usually the wrong answer — too long, too detailed, aimed at contributors rather than evaluators.

Docent is not a substitute for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far — written for visitors who are deciding whether to pay attention, not for developers already using it.

## How it works

Docent is distributed as a Claude Code plugin. Two commands install it into any Claude Code session; one conversation sets up the site. During init, Docent asks about tone and update cadence, reads the repo for design signals (logo, badges, metadata), scaffolds a static site under `/docs` using a bundled Astro template, generates the first round of content, and opens a pull request.

After the PR is merged, a daily Routine keeps the site current. Each morning it checks what's stale, decides whether there's enough recent activity to write a journal post, and produces a PR with whatever combination makes sense — content refresh, new journal post, both, or nothing. The decision is made by the skill itself based on activity since the last run, not a fixed schedule.

Docent has five modes:

- **`init`** scaffolds the site and writes the first content.
- **`update`** refreshes the status page, overview, and changelog as the repo evolves.
- **`digest`** writes a journal post summarizing recent activity on demand.
- **`release`** converts a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without ever touching them automatically.

All generated content lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; the site template is yours to adjust.

## Getting started

[Install the plugin](https://github.com/calumjs/docent#installing-it-in-a-repo) into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps and the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
