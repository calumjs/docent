Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, and writes a small site that explains what the project is, what's been shipping, and what's open. The site lives in `/docs` inside the same repo and deploys to GitHub Pages.

## Who it's for

A solo maintainer or a small team with a project worth surfacing beyond its repository. Docent is for the moment when someone arrives from a link or a search result and wants to know "what is this and should I care?" — and currently gets a wall of Markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works; Docent describes what a project *is* — the pitch, the current status, the story so far — for visitors who might never open the code.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any session; one conversation then sets up the site. The skill reads the repo for design signals — logo, badges, repo metadata — scaffolds an Astro site under `/docs`, generates an overview, a status page, a changelog, and an inaugural journal post, and opens a pull request.

After the PR is merged, a daily Routine keeps the site current. The Routine decides on each run whether to refresh the status page, write a journal post, or both — based on what's happened since the last run. Nothing goes live without a pull request.

No hosted service, no API keys, no backend. Inference runs through your Claude Code subscription.

Five pages are generated:

- **Overview** — what the project is and who it's for
- **Journal** — summaries of recent activity on a configurable cadence
- **Status** — open issues grouped and described
- **Changelog** — release notes derived from tags and merged PRs
- **Bug/feature forms** — pre-filled GitHub issue openers

The generated content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the plugin, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
