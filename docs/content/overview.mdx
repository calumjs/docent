Docent takes a GitHub repository and builds a public-facing static site from what's already there — commits, issues, releases, and the README. The site lives under `/docs` inside the same repository, deploys to GitHub Pages, and stays current through a daily Claude Code Routine. No separate hosting, no API keys beyond your Claude Code subscription, no backend.

## Who it's for

A solo maintainer or small team with a project that gets visitors who aren't going to read the code. Someone arrives from a search result, a link a colleague shared, or a mention somewhere. They want to know what this thing is and whether they should care. A README answers that for contributors; Docent answers it for everyone else.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far — for visitors who may never open the code.

## How it works

Docent is a Claude Code plugin. Two install commands add it to any Claude Code workspace. Telling it to set up the site starts a conversation: Docent asks about tone and update cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request.

After the PR merges, a single daily Routine keeps the site current. The Routine checks what has changed — README, open issues, new release tags — and decides whether to refresh the status page, write a journal post, both, or nothing. Every update goes through a pull request; nothing is pushed directly.

The site includes five sections:

- **Overview** — an explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity, on a configurable cadence
- **Status** — open issues grouped and summarized, refreshed on each run
- **Changelog** — release notes derived from tags and merged pull requests
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues

Generated content lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the template.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside the target repository:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
