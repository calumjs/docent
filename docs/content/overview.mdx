Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, then writes a small site that explains what the project is, what's been shipping, and what's open. Nothing requires a hosted service, an API key, or a separate backend.

## Who it's for

A maintainer with a project that deserves a better introduction than a README. When people arrive from search or a shared link, they typically land on a wall of Markdown aimed at people who already know what the project does. Docent addresses a different visitor: someone deciding whether to care.

The site Docent generates answers the questions that visitor actually has: what is this, who is it for, what's been happening, what's broken, what's coming next. It is not API documentation — tools like Docusaurus or MkDocs do that. Docent's scope is narrower and different: the pitch, the status, the story so far.

A concrete example: you've built a CLI tool that a few dozen people are using, some have starred, and occasionally someone shows up wanting to understand it before trying it. A README explains the flags. Docent explains the tool.

## How it works

Docent is a Claude Code plugin. Installing it takes two commands in any Claude Code session inside your repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

From there, one conversation — "set up Docent for this repo" — runs the `init` procedure. It asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a single daily Routine keeps the site current. The Routine decides for itself whether to refresh the status page, write a journal post, both, or nothing — based on what's happened in the repo since the last run. Every change goes through a pull request.

The content Docent writes lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the plugin, then open Claude Code inside your repo and say "set up Docent for this repo." See the [README](https://github.com/calumjs/docent) for full install steps, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
