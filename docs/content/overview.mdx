Docent reads a GitHub repository — its README, commits, issues, and releases —
and produces a static site that answers the question visitors actually ask: what
is this project and should I care? The site lives in `/docs`, deploys to GitHub
Pages, and stays current through a scheduled Claude Code Routine.

## Who it's for

Solo maintainers and small teams whose projects deserve a better first impression
than a README. When someone arrives from a search result or a shared link, they
usually want a human-readable answer to "what is this and should I care" —
not a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs.
Those describe how a library works. Docent describes what a project *is*: the
pitch, what's been shipping, what's open, what's coming — for visitors who may
never look at the code.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any session.
Say "set up Docent for this repo" and the skill handles the rest: it reads the
repo for design signals, scaffolds an Astro site under `/docs`, generates the
initial content, and opens a pull request.

After the PR merges, a daily Routine keeps the site current. Each run checks what
has changed since the last update and decides whether to refresh content, write a
journal post, or both. Nothing goes live without a pull request.

Docent has five modes, each a distinct procedure:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues without touching them automatically.

Generated content lives in `/docs/content/` as structured MDX and JSON. An Astro
template in `/docs/src/` renders it. Docent owns the content; you own the
presentation.

## Getting started

Install the skill, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent)
for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md)
for the design.
