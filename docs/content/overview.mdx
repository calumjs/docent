Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, and the README — and writes a site that explains what the project is, what has been shipping, and what is currently open. The site lives in `/docs` inside the repo, deploys to GitHub Pages, and updates on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or a small team whose project gets external attention but whose README alone doesn't answer the question a first-time visitor actually asks: "what is this and should I care?" Docent is useful when people arrive from a search result or a shared link and find a wall of markdown where they expected a project page.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how to use a library. Docent describes what a project *is* — the pitch, the story so far, the current state — for visitors who may never write a line of code against it.

## How it works

Installing Docent takes two commands in Claude Code. From there, one conversation sets up the site: Docent reads the repo for design signals, asks about tone and cadence, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request.

The site has five sections:

- **Overview** — a written explanation of the project, derived from the README
- **Journal** — posts summarizing recent activity, generated on a configured cadence
- **Status** — open issues grouped and summarized
- **Changelog** — entries derived from release tags and merged pull requests
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab

After the initial pull request is merged, a daily Routine keeps the site current. Each run checks whether anchors have drifted — whether the issue set has changed, whether the README has been updated, whether new tags have appeared — and decides whether there is enough recent activity to write a new journal post. It then opens a pull request containing whatever combination of content refresh and new post is warranted, or nothing if everything is already fresh.

## Getting started

[See the README](https://github.com/calumjs/docent) for the two install commands and the full setup walkthrough. The short version: install the plugin, say "set up Docent for this repo," and merge the PR it opens.
