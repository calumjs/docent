Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, then writes a small site that explains what the project is, what's shipping, and what's open. The site lives in `/docs` inside your repo and deploys to GitHub Pages.

## Who it's for

A solo maintainer or a small team whose project deserves a better public face than a README. The immediate use case: someone arrives from a search result or a link, wants to understand whether the project is relevant to them, and currently encounters a wall of markdown.

Docent isn't a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent answers the earlier question — "what is this and should I care?" — for visitors who will never read the code.

## How it works

Two install commands bring the skill into a Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, a daily Routine keeps the site current. Each morning it checks what has drifted — status page, overview, changelog — decides whether there's enough activity to write a journal post, and produces a PR with whatever combination makes sense. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues without touching them automatically.

Generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves stay separate: Docent writes the content; you own the presentation.

## Getting started

Install the plugin in any Claude Code session inside your target repo, then say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for install commands and the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full design.
