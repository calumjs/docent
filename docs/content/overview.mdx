Docent turns a GitHub repository into a public-facing static website. It reads your commits, issues, and releases, then writes a small site that explains what the project is, what has been shipping, and what is currently open. The site lives in `/docs` inside the same repo and deploys to GitHub Pages.

## Who it's for

Docent is for solo maintainers and small teams whose projects deserve a better introduction than a README. When people arrive via search or a link and want a human-readable answer to "what is this and should I care," a wall of markdown is not it.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is* — the pitch, the current status, the story so far — for visitors who may never read the code.

## How it works

Two install commands add the skill to any Claude Code session. From there, one conversation sets up the site: Docent reads the repo for design signals, asks about tone and cadence, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request. After merging, a daily Routine keeps the site current.

The Routine runs each morning and decides, based on what has happened in the repo since the last run, whether to refresh the status page, write a journal post, or both. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** — scaffolds the site from scratch and writes the first content.
- **`update`** — refreshes the status page and overview as issues and the README change.
- **`digest`** — writes a journal post summarizing recent activity.
- **`release`** — turns a new tag into a changelog entry.
- **`triage`** — drafts suggestions for new issues, without touching them automatically.

Generated content lives in `/docs/content/` as MDX and JSON. An Astro site template in `/docs/src/` renders it. Docent writes the content; you own the presentation. No hosted service, no API keys, no backend — inference runs through your Claude Code subscription.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

The init procedure handles the rest. See the [README](https://github.com/calumjs/docent) for full install steps and manual configuration options.
