Docent converts a GitHub repository into a self-maintaining public website. Given a repo's README, commits, issues, and releases, it writes a structured site that explains the project to people who didn't write the code. The site lives in `/docs` inside the same repository and deploys to GitHub Pages.

## Who it's for

A developer with a project worth sharing, whose repository reads as opaque from the outside. When someone finds your repo and immediately wonders "what is this actually for?" — Docent writes the page that answers that question.

Docent is not a documentation generator. It doesn't describe APIs, methods, or module structure. It describes the project: what it does, what's been happening, what's open. The intended audience is someone who might become a user or contributor, not someone already reading the source.

## How it works

Two install commands add the skill to any Claude Code session. One conversation sets up the site: Docent inspects the repository for design signals, picks a visual style from four options, scaffolds an Astro site under `/docs`, generates the first content, and opens a pull request.

After merging, a daily Routine handles maintenance. Each morning it checks whether the README has changed, new issues have opened, or new releases have been tagged — and opens a PR with whatever needs updating. When enough has shipped to be worth writing about, it writes a journal post. When nothing meaningful has changed, it does nothing.

Generated content lives in `/docs/content/` as MDX and JSON. The Astro template in `/docs/src/` renders those files into a site. Docent writes the content; the template handles presentation. Either half can be modified independently.

Docent currently produces five pages:

- **Overview** — what the project is, who it's for, how to get started
- **Journal** — posts summarizing recent activity, written when enough has happened to write about
- **Status** — open issues grouped and described, updated when the issue set changes
- **Changelog** — release notes built from tags and merged PRs
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab

No hosted service, no API keys, no backend. Inference runs through your Claude Code subscription via the daily Routine.

## Getting started

Docent is a Claude Code plugin. In any Claude Code session inside the repository you want to set up:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **"set up Docent for this repo."**

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps and [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full design.
