Docent turns a GitHub repository into a public-facing static website. It reads
the repo — commits, issues, releases, the README — and generates a small site
that tells visitors what the project is, what has been shipping, and what is
open. The site lives in `/docs` inside the same repository, deploys to GitHub
Pages, and keeps itself current through a scheduled Claude Code Routine.

## Who it's for

Docent serves solo maintainers and small teams whose repos receive traffic from
outside the contributor circle — from search results, a link in a newsletter,
or a mention in another project. When those visitors arrive, a README often
gives them too much of the wrong thing: implementation detail, not an answer to
"should I use this?"

There is no hosted backend, no separate API keys, and no additional deploy
system beyond what GitHub Pages already provides. The overview page answers
"what is this and who is it for." The journal records what has been happening.
The status page surfaces open issues, grouped and summarized. The changelog
turns tagged releases into readable notes. Bug report and feature request forms
open pre-filled GitHub issues in a new tab.

## How it works

Docent is a Claude Code plugin. Two commands install it into any session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

After installation, one conversation sets up the site. The `init` procedure
asks about tone and cadence, reads the repository for design signals, scaffolds
an Astro site under `/docs`, generates the first content, and opens a pull
request. Merging that PR and enabling GitHub Pages completes the installation.

A daily Routine keeps the site current. Each morning it checks whether the
issue list has changed, whether the README has drifted, and whether there is
enough recent activity to write a journal post. It regenerates only what is
stale, then opens another pull request. Nothing goes live without a PR.

Five modes cover the common operations: `init`, `update`, `digest`, `release`,
and `triage`. Any of them can be invoked directly: "Docent, write a journal
post about the auth refactor."

## Getting started

Install the plugin in a Claude Code session inside your target repository and
say "set up Docent for this repo." The [README](https://github.com/calumjs/docent)
covers the full install steps, including the two post-merge tasks: enabling
GitHub Pages and scheduling the update Routine.
