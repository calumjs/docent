Docent is a Claude Code plugin that reads a GitHub repository and produces a small public website from what it finds. Give it a repo with commits, issues, releases, and a README, and it generates an Astro site that tells visitors what the project is, what has been shipping, and what's currently open — without writing a word of it by hand.

## What it's for

Most GitHub repos don't have a good front door. The README describes the code; it doesn't answer "should I care?" for someone who arrived from a search result or a friend's recommendation. Docent fills that gap.

It's useful when you have a project that deserves a better introduction than a wall of markdown — when you want visitors to understand the project's story (what landed, what's broken, what's coming) without digging through commit history, and when you want that front door to stay current automatically rather than drifting out of date the moment you get busy.

Docent is not a replacement for documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the recent history, the current state — for visitors who might never read the code.

## How it works

Two install commands bring Docent into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates initial content, and opens a pull request. After that PR merges, one manual step sets up the daily Routine:

```
/schedule Docent update daily at 08:00 — prompt: "Docent: run update mode."
```

Each day the Routine checks whether the status page, overview, or changelog have drifted, and decides whether recent activity warrants a journal post. It opens a PR with any updates, or exits silently if there's nothing worth writing. Nothing goes live without a pull request.

Docent has five modes, each a self-contained procedure:

- **`init`** — scaffolds the site and generates first content
- **`update`** — refreshes status, overview, and changelog on schedule
- **`digest`** — writes a journal post summarizing a period of activity
- **`release`** — turns a new tag into a changelog entry
- **`triage`** — drafts suggestions for newly opened issues

The generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro site template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the plugin, open Claude Code inside your repo, and say **set up Docent for this repo**. The skill walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
