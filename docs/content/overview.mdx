Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then generates a small site that explains what the project is, what's been shipping, and what's open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and keeps itself current through a daily scheduled Routine.

## Who it's for

A solo maintainer or a small team whose project deserves a better introduction than a wall of markdown. Docent is useful when someone arrives from search or a link and needs a human-readable answer to "what is this and should I care" — and currently gets a technical README written for contributors.

Docent is not a documentation tool. Tools like Docusaurus and MkDocs document *how* a library works. Docent describes *what* a project is: the pitch, the status, the story of what's shipped — for visitors who may never read the code.

## How it works

Two install commands bring the plugin into any Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content pages, and opens a pull request. After the PR is merged, a daily Routine runs the update mode — checking whether the status page, overview, or changelog need refreshing, and deciding whether recent activity warrants a journal post.

Docent has five modes, each a self-contained procedure that runs when asked:

- **`init`** scaffolds the `/docs` site and generates the first content.
- **`update`** refreshes stale pages and optionally adds a journal post.
- **`digest`** writes a journal post summarizing a specific period.
- **`release`** turns a new git tag into a changelog entry.
- **`triage`** drafts suggestions for new issues without editing them.

Generated content lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; the maintainer owns the presentation.

## Getting started

Install the plugin into a Claude Code session in your target repo, then say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
