Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, and the README — and writes a small site that tells the project's story to visitors who might never read the code.

## Who it's for

A maintainer or small team with a project that deserves a better introduction than a README. When people arrive via a search result or a shared link, they want one clear answer to "what is this and should I care?" — currently they get a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the recent activity, what's open, what's coming — for visitors who want context, not a function reference.

## How it works

Two install commands add the skill to any Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After merging, two manual steps enable GitHub Pages and wire up a daily Routine that keeps the site current.

The Routine runs once a day and decides for itself what to do: refresh the status page, write a journal post, both, or nothing — based on what's happened in the repo since the last run. Routines use your Claude Code subscription tokens, with no API key required. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the overview, status page, and changelog as the repo changes.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

Generated content — the overview, journal posts, status summaries, and changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro site template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the plugin in any Claude Code session inside your target repo, then say `set up Docent for this repo`. See the [README](https://github.com/calumjs/docent) for the two install commands and what happens next, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full design.
