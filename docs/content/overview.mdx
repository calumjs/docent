Docent turns a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site explaining what the project is, what has been shipping, and what is open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team with a project that deserves a clearer introduction than a README. If people arrive from a link or search result and want to know whether the project is worth their time, Docent gives them a page that answers that without requiring them to read source code.

A specific case: you maintain a CLI tool or a small library. The README covers installation and flags. But a visitor skimming GitHub sees dense Markdown and no narrative. Docent generates an overview, a running journal of recent work, a status page grouping open issues, and a changelog derived from release tags — all from what the repo already contains.

Docent is not documentation in the Docusaurus or MkDocs sense. Those tools describe how a library works. Docent describes what a project *is*: the pitch, current status, and recent history — for visitors who might never read the source.

## How it works

Docent is a Claude Code plugin. Installing it adds the `docent` skill to any Claude Code session in your target repo. The skill has five modes:

- **`init`** scaffolds the site, generates the initial content, and opens a pull request.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** converts a new release tag into a changelog entry.
- **`triage`** drafts issue suggestions without touching the tracker automatically.

Generated content lives in `/docs/content/` as MDX and JSON files. An Astro template in `/docs/src/` renders it. Docent owns the content half; you own the presentation. Nothing goes live without a pull request.

A daily Routine decides on each run whether to refresh content, write a journal post, both, or nothing — based on what has happened in the repo since the last run.

## Getting started

Install the plugin in any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps and post-merge configuration, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
