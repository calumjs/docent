Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, and the README — and produces a small site that explains what the project is, what's been shipping, and what's open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and stays current through a daily scheduled routine.

## Who it's for

Docent is for solo maintainers and small teams whose projects deserve a better introduction than a README. When someone arrives from search, a link, or a mention elsewhere, they want a readable answer to "what is this and should I care" — not a wall of markdown addressed to contributors.

It isn't a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far, and how to leave feedback — for visitors who may never read the code.

## How it works

Docent is a Claude Code plugin. Two install commands bring it into any session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

From there, saying "set up Docent for this repo" starts the `init` procedure. Docent reads the project, asks about tone and update cadence, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After merging, a daily Routine keeps the site current — deciding for itself whether to refresh the status page, write a journal post, both, or nothing, based on what's happened in the repo since the last run.

Generated content — overview, journal posts, status summaries, changelog entries — lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

Docent has five modes:

- **`init`** scaffolds the site and generates the first round of content.
- **`update`** refreshes the status page, overview, and changelog as the repo changes.
- **`digest`** writes a journal post on demand for a topic you name.
- **`release`** turns a new tag into a formatted changelog entry.
- **`triage`** drafts suggestions for newly opened issues, without acting on them automatically.

## Getting started

Install the plugin in any Claude Code session inside your target repo, then say "set up Docent for this repo." Docent handles the rest: asks a few questions, scaffolds the site, opens a pull request. After merging, one more step sets up the daily Routine that keeps the site current.

[See the README for the full install steps](https://github.com/calumjs/docent), or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full design.
