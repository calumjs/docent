Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads your commits, issues, releases, and README, then writes a small site that explains what the project is, tracks what has shipped, and surfaces what is open. The site lives in `/docs` inside your own repo, deploys to GitHub Pages, and updates itself on a schedule through a Claude Code Routine.

## Who it is for

A maintainer or small team with a project that deserves a better introduction than a wall of Markdown. Docent is useful when someone arrives from a search result, a link, or a mention and wants a readable answer to "what is this and should I care" — without having to read the source code to find out.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works; Docent describes what a project *is*. The pitch, the status, the recent story — for visitors who might never open a code file.

## What the site includes

An initialized Docent site has five sections:

- **Overview** — a synthesized explanation of the project drawn from the README and commit history.
- **Journal** — a running log of what has shipped, written automatically by the same Routine that keeps the rest current.
- **Status** — open issues grouped by theme, so a visitor can quickly see what is known and what is in progress.
- **Changelog** — human-readable release notes derived from tags and merged PRs, without manually writing them.
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab. No backend.

## How it works

Two install commands bring the skill into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**. The skill reads the repo for design signals, asks a few questions about tone and cadence, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After merging, enable GitHub Pages with Actions as the source and schedule a daily Routine to keep the content fresh.

The Routine uses your existing Claude Code subscription — no additional API key is required. Each morning it checks what has changed, decides whether to refresh the status page, write a journal post, both, or nothing, and opens a PR if anything is worth updating.
