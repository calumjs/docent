Docent is a Claude Code plugin that reads a GitHub repository — commits, issues, releases, and the README — and produces a static site that explains the project to people who didn't write the code. The site deploys to GitHub Pages from inside the same repo, updates itself on a schedule, and requires no hosted service or API keys beyond a Claude Code subscription.

## Who it's for

A maintainer or small team with a project that deserves a better public presence than a raw README. The problem Docent solves is specific: someone lands on your repo from a search result or a shared link and wants a plain-English answer to "what is this and should I care?" — and currently gets a wall of markdown.

Docent is not a documentation tool. It doesn't describe an API surface or explain function signatures. It tells the story of the project: the pitch, the current status, what has been shipping lately. The audience is visitors who might never read the code, not contributors who already have.

## What the site includes

A live site at `username.github.io/project` with five sections:

- **Overview** — a written explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized, with bugs and in-progress work called out
- **Changelog** — human-readable release notes derived from tags and merged PRs
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues

## How it works

Install the plugin with two commands in any Claude Code session, then say "set up Docent for this repo." The skill runs its `init` mode: asks about tone, cadence, and domain; scaffolds an Astro site under `/docs` from a bundled template; analyzes the repo for design signals; generates the first round of content; and opens a pull request.

After merging, you enable GitHub Pages (Actions as the source) and set up a daily Routine:

```
/schedule Docent update daily at 08:00 — prompt: "Docent: run update mode."
```

From then on, the Routine decides for itself — on each run — whether to refresh the status page, write a journal post, both, or nothing, based on what has happened in the repo since the last run. Nothing goes live without a pull request.

You can also invoke Docent directly at any time: *"Docent, write a journal post about the auth refactor."*

## Getting started

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then open Claude Code inside your repo and say: **set up Docent for this repo**

Full install steps are in the [README](https://github.com/calumjs/docent). Design and schema details are in the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md).
