Docent reads a GitHub repository — its commits, issues, releases, and README — and writes a small website explaining what the project is, what's shipping, and what's open. The site lives under `/docs` inside the same repo and deploys to GitHub Pages. No hosted service, no extra API keys.

## Who it's for

A solo maintainer or small team whose project gets visitors from search or shared links, and those visitors currently get a wall of markdown. Docent is not an API documentation generator. It doesn't describe how a library works internally. It describes what the project *is* — the pitch, the current status, recent activity — for readers who may never look at the code.

The contrast is concrete: a developer searching for a self-hosted tool lands on a README, squints at the dependency list, and leaves. The same developer landing on a Docent-generated overview reads a clear description, checks the status page for known bugs, and decides whether to dig further.

## How it works

Install the plugin in any Claude Code session inside your target repo with two commands. Then say "set up Docent for this repo." The skill asks about tone and update cadence, reads the repo for design signals to pick a visual style, scaffolds an Astro site under `/docs`, generates an overview, status page, changelog, and inaugural journal post, and opens a pull request.

After merging, enable GitHub Pages (one `gh api` command or a settings toggle) and schedule a daily Routine with `/schedule`. The Routine runs each morning, checks what's stale, decides whether to refresh content or write a journal post, and opens a PR if there's anything to update. Nothing goes live without a PR.

The generated content — MDX and JSON files under `/docs/content/` — is owned by Docent. The Astro site template in `/docs/src/` is yours to modify. The two halves stay separate by design.

## Getting started

Two plugin commands and one conversation with Claude Code get you to a merged PR with a live site. See the [README](https://github.com/calumjs/docent) for the exact steps.

After that, the site maintains itself. You can also invoke Docent manually at any point — "Docent, write a journal post about the recent refactor" — and it opens a PR.
