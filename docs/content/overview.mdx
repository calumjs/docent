Docent turns a GitHub repository into a static, public-facing website. It reads the repo — the README, commits, issues, and release tags — and generates a site that tells visitors what the project is, what's been shipping, and what's open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and keeps itself current through a daily routine.

## Who it's for

Docent is useful when people find your project from a link, a search result, or word of mouth, and need a readable answer to "what is this and should I care?" A wall of markdown doesn't serve that visitor.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far — for people who might never read the code.

The target is a solo maintainer or a small team whose project gets outside traffic. If the only people reading your repo are the people committing to it, Docent won't add much. If visitors arrive from outside, it fills a real gap.

## How it works

Two install commands bring Docent into any Claude Code session as a plugin. One conversation sets up the site: Docent reads the repo for design signals, picks a visual vibe, scaffolds an Astro site under `/docs`, generates the first round of content — overview, status page, changelog, inaugural journal post — and opens a pull request.

After the PR merges, a daily routine keeps the site current. Each run checks whether the status page is stale (issues changed), whether the overview needs refreshing (README changed, or it's been a while), and whether enough has happened to be worth a journal post. The routine produces a PR with whatever combination makes sense — or nothing, if everything is already current.

Docent has five modes, each a self-contained procedure:

- **`init`** scaffolds the site and generates the first content.
- **`update`** refreshes the status page, overview, and changelog as the repo changes.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

The generated content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the plugin into your Claude Code session, then say "set up Docent for this repo":

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, including the two manual steps you'll need after merging the setup PR (enabling GitHub Pages and scheduling the daily routine).
