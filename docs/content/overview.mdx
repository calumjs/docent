Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, then produces a small site at `username.github.io/project` that explains what the project is, what's been shipping, and what's open — for visitors who won't read the code.

## Who it's for

A solo maintainer or small team with a project that deserves a better introduction than a README wall. The expected visitor arrived via a link or a search result and wants a plain-language answer to "what is this and should I use it" — without having to parse installation instructions or a contributing guide to get there.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those explain how a library works. Docent explains what a project *is*: the pitch, the current state, the story so far.

## How it works

Two commands install the plugin into any Claude Code session. From there, a single conversation sets up the site: Docent reads the repo for design signals, asks a few questions about tone and cadence, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, one Routine keeps the site current. The Routine runs on a schedule and decides for itself whether to refresh the status page, write a journal post, both, or nothing — based on what's landed in the repo since the last run. Each change goes out as a pull request, not a direct push.

Docent has five modes: `init` scaffolds the site, `update` refreshes content on a schedule, `digest` writes a journal post on demand, `release` turns a new tag into a changelog entry, and `triage` drafts suggestions for open issues.

The generated content — overview, journal posts, status summary, changelog — lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the plugin in any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **"set up Docent for this repo."** Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full setup steps, including enabling GitHub Pages and wiring up the Routine.
