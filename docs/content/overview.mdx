Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, then writes a small site that explains what the project is, what has been shipping, and what is open — for visitors who may never look at the code.

## Who it's for

Most repos have a README, but a README is written for someone already holding the code. Docent is for a different visitor: someone who arrives from search or a link, wants to know whether the project is relevant to them, and needs a human-readable answer to "what is this."

That visitor shows up for a solo maintainer's open-source library, a small team's internal tool that has graduated to external users, or any project where the gap between "GitHub page" and "a real web presence" is costing the project interest it deserves. Docent is not a replacement for API documentation tools like Docusaurus or MkDocs — those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far.

## How it works

Docent is a Claude Code plugin — two commands install it into any session. Once installed, a single conversation sets up the site: Docent asks about tone and update cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the first round of content, and opens a pull request. After merging, the site deploys to GitHub Pages.

Content lives in five sections — Overview, Journal, Status, Changelog, and forms for bug reports and feature requests. Each is a structured MDX or JSON file in `/docs/content/`; the Astro template in `/docs/src/` renders them. The two halves are owned separately: Docent writes the content; you own the presentation.

A daily Routine keeps the site current. It checks what has changed in the repo and decides for itself whether to refresh the status page, write a journal post, both, or nothing — based on what has actually happened since the last run. Inference runs through your Claude Code subscription. No hosted service, no API keys, no backend.

## Getting started

Two commands install the plugin, then open Claude Code and say "set up Docent for this repo." See the [README](https://github.com/calumjs/docent) for the install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full technical design.
