Docent is a Claude Code plugin that generates a public-facing website for any GitHub repo and keeps it current on a schedule. Two install commands and a brief conversation scaffold a small Astro site under `/docs` that explains the project, tracks open work, and posts journal entries as activity lands — no hosted backend, no separate API key.

## Who it's for

A solo maintainer or small team whose project deserves a better front door than a README. Docent is useful when people arrive from a search result or a link and want to know whether a project is relevant to them, what's being worked on, and whether it's actively maintained — without reading source code.

Docent is not a substitute for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is* and what's been happening: an overview, a status snapshot, a changelog, a journal.

## How it works

Two install commands bring the skill into any Claude Code session. From there, asking "set up Docent for this repo" starts the init process: Docent asks a few questions about tone and cadence, analyzes the repo for design signals, scaffolds an Astro site from a bundled template, generates the initial content, and opens a pull request.

After that PR merges, a daily Routine keeps the site current. Each run decides for itself whether to refresh the status page, write a journal post, or both — based on what's changed since the last run. Nothing goes live without a pull request. Every generated file records a source anchor so the next run can tell what's stale and what isn't.

Docent has five modes:

- **`init`** sets up the site and generates the first content pass.
- **`update`** refreshes the status page, overview, and changelog as the repo changes.
- **`digest`** writes a journal post summarizing a period of activity.
- **`release`** generates a changelog entry for a tagged release.
- **`triage`** drafts suggestions for new issues, without ever touching them automatically.

## Getting started

Install the plugin, then open Claude Code and say:

```
set up Docent for this repo
```

See the [README](https://github.com/calumjs/docent) for the full install steps. No `ANTHROPIC_API_KEY` to configure — the Routine runs on your Claude Code subscription.
