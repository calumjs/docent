Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, the README — and writes a small site that tells visitors what the project is, what has shipped, and what is currently open. The site lives in `/docs`, deploys to GitHub Pages, and updates on a schedule through Claude Code Routines.

## Who it's for

Docent is for projects that get visitors — from search, a link, or word of mouth — who need a better introduction than a README. A README answers contributor questions: how to clone, what the architecture is, how to run the tests. Docent answers visitor questions: what does this do, should I care, what has changed lately.

It's not an API documentation tool. Tools like Docusaurus or MkDocs describe how a library works in detail. Docent describes what a project *is*: the pitch, the status, and the story so far, for someone who might never read the code.

## How it works

Docent is a Claude Code plugin. Two commands install it into any session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

From there, one conversation handles setup. Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After merging, a daily Routine keeps the site current — checking what's stale, deciding whether to write a journal post, and opening a PR with whatever combination makes sense. Nothing goes live without a pull request.

The generated content includes five sections:

- **Overview** — an explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity, written automatically or on demand
- **Status** — open issues grouped and summarized from the issue tracker
- **Changelog** — human-readable release notes derived from tags and merged PRs
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues

## Getting started

Install the plugin into any Claude Code session inside your repo, then say:

> set up Docent for this repo

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the full technical design.
