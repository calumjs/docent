Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, and writes a small site that describes what the project is, what's been shipping, and what's currently open.

## Who it's for

A project usually has two audiences: contributors who read the code, and everyone else. The README serves contributors well. It describes setup, structure, and conventions for people already working in the repo. It's less useful for someone who arrives from a link or a search result and wants a plain-language answer to "what does this do and should I care."

Docent fills that gap. The site it generates has an overview written for first-time visitors, a journal summarizing recent activity in plain prose, a status page grouping open issues by theme, and a changelog derived from release tags. None of these require writing by hand after the initial setup — an automated Routine keeps them current on whatever schedule you set.

## How it works

Docent installs in two commands inside any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

One conversation handles setup: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. After that PR merges, a Routine keeps things current. Update mode runs on schedule, decides whether anything has changed, and opens a new PR with refreshed content — or exits silently if nothing's stale. Nothing goes live without a pull request.

The five pages it maintains — Overview, Journal, Status, Changelog, and feedback forms — are written as structured MDX and JSON in `/docs/content/`. An Astro template renders them. Docent owns the content; the template is yours to modify.

## Getting started

Install the plugin into a Claude Code session pointed at your repo, then say:

```
set up Docent for this repo
```

Docent walks through the rest. Full install steps are in the [README](https://github.com/calumjs/docent).
