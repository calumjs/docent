Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static site. It reads commits, issues, releases, and the README, then writes a small site that explains what the project is, what has shipped, and what is open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates itself on a schedule — no hosted service, no API keys, no backend.

## Who it's for

A solo maintainer or small team with a project that deserves a better introduction than a raw README. When someone finds the project via search or a link, they typically get a wall of markdown. Docent gives them a human-readable front door instead: the pitch, the current status, the story so far.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works at the method level. Docent describes what a project *is* — enough to decide whether to install it, follow it, or contribute.

## How it works

Two install commands bring the plugin into any Claude Code session. One conversation sets up the site: Docent's `init` mode asks about tone and cadence, reads the repository for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. Each run checks whether the status page, overview, or changelog has drifted since the last update. If enough has happened in the repo, it also writes a journal post. Everything goes into a pull request — nothing publishes automatically without one.

Docent has five modes:

- **`init`** — scaffolds `/docs` and writes the first content.
- **`update`** — refreshes status, overview, and changelog as issues and the README change.
- **`digest`** — writes a journal post summarizing recent activity.
- **`release`** — turns a new tag into a changelog entry.
- **`triage`** — drafts suggestions for new issues, without touching them automatically.

## Getting started

Install the plugin in any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo.** Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
