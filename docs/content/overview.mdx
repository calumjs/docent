Docent reads a GitHub repository — its commits, issues, releases, and README — and writes a small static site that explains what the project is, what has shipped, and what is open. The site lives in `/docs` inside the same repo and deploys to GitHub Pages on a schedule through Claude Code Routines.

## Who it's for

A maintainer or small team whose project needs a public face beyond the README. Docent is useful when visitors arrive from search or a link and want a plain-language answer to "what is this and should I care" — currently answered by a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs, which describe how a library works. Docent describes what a project *is*: the pitch, the status, the story of what has shipped — aimed at visitors who may never read the code.

## How it works

Two install commands add the skill to any Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a scheduled Routine keeps the site current. The Routine decides each day whether to refresh the status page, write a journal post, or both — based on what has happened in the repo since the last run. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

The generated content — overview, journal posts, status summaries, changelog — lives in `/docs/content/` as structured MDX and JSON. An Astro site template in `/docs/src/` renders it. The two halves are owned separately: Docent writes the content; you own the presentation.

## Getting started

Install the skill, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for the full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
