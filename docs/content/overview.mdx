Docent turns a GitHub repository into a public-facing static website. It reads
the repo — commits, issues, releases, the README — and writes a small site that
explains what the project is, what's been shipping, and what's open. The site
lives in `/docs` inside the same repo, deploys to GitHub Pages, and keeps
itself current on a daily schedule through Claude Code Routines.

## Who it's for

A solo developer or small team with a project that deserves a proper introduction.
The common situation: someone finds the repo via a link or search, lands on a
README wall, and has no clear answer to "what is this and should I care?"

Docent is not an API documentation tool — Docusaurus and MkDocs already exist
for that. Docent documents what a project *is*: the pitch, the current status,
and the story so far, for visitors who may never read the code.

## How it works

Docent is a Claude Code plugin. Two commands bring the skill into any session,
after which a single conversation sets up the site: Docent reads the repo for
design signals, scaffolds an Astro site under `/docs`, generates initial
content, and opens a pull request.

After merging, a daily Routine keeps things current. Each run checks what has
drifted — the README, the open issues, the tag list — decides whether enough
has happened to write a journal post, and opens a PR containing whatever
combination makes sense: a content refresh, a new post, both, or nothing.

Five modes cover the full lifecycle:

- **`init`** — scaffold the site and write the first content
- **`update`** — refresh the status page and overview as issues and the README change
- **`digest`** — write a journal post summarizing recent activity (runs as part of the daily Routine, or on demand)
- **`release`** — turn a new tag into a changelog entry
- **`triage`** — draft suggestions for new issues, without touching them automatically

The generated content lives in `/docs/content/` as MDX and JSON. An Astro
template in `/docs/src/` renders it. The two halves are owned separately:
Docent writes the content; you own the presentation.

## Getting started

Install the plugin into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest.
[See the README](https://github.com/calumjs/docent) for the full install
steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md)
for the design.
