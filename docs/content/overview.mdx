Docent turns a GitHub repository into a public-facing static website. It reads the repo — commits, issues, releases, the README — and writes a small site that explains what the project is, what has been shipping, and what is open. The site lives in `/docs` inside the same repo, deploys to GitHub Pages, and updates itself on a schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team with a project that deserves a better first impression than a README. Docent is useful when people arrive from search or a link and want a human-readable answer to "what is this and should I care" — and currently get a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story of what has shipped.

## What it produces

A live site at `username.github.io/project` with five sections:

- **Overview** — a written explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized, with known bugs and in-progress work separated
- **Changelog** — release notes derived from tags and merged PRs
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues

## How it works

Two install commands bring the skill into any Claude Code session. From there, one conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. The Routine decides whether to refresh the status page, write a journal post, or both — based on what has happened in the repo since the last run. Nothing goes live without a pull request.

Docent has five modes, each a procedure the skill runs when you ask for it:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

## Getting started

In any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

See the [README](https://github.com/calumjs/docent) for the full install steps, including enabling GitHub Pages and scheduling the daily Routine. The [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) has the full design.
