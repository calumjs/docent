Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, and writes a site that explains what the project is, what has been shipping, and what is currently open. The site lives in `/docs`, deploys to GitHub Pages, and updates itself on a daily schedule through Claude Code Routines. No hosted service, no API keys, no backend.

## What it produces

A live site at `username.github.io/project` with five sections:

- **Overview** — an AI-written explanation of what the project is and who it's for.
- **Journal** — posts summarizing recent activity, written on a configurable cadence.
- **Status** — open issues grouped by type, with bugs and in-progress work surfaced.
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab.
- **Changelog** — human-readable release notes derived from tags and merged PRs.

## Who it's for

A solo maintainer or small team whose project deserves a better introduction than a README. Docent is useful when someone arrives from a search result or a shared link and wants a plain-language answer to "what is this and should I care" — and currently finds only a wall of Markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the story so far — for visitors who may never read the code.

## How it works

Two commands install Docent as a Claude Code plugin inside your target repo. From there, one conversation runs the `init` procedure: it asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging the PR, a single Claude Code Routine keeps the site current. The Routine runs `update` mode on a schedule: it checks which content is stale, decides whether there is enough recent activity to warrant a journal post, and produces a PR containing whatever combination makes sense — content refresh, a new post, both, or nothing.

## Getting started

Install the plugin, then open Claude Code inside your repo and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps, configuration options, and the one-time GitHub Pages setup that only the repo owner can do.
