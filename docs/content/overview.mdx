Docent turns a GitHub repository into a public-facing static website. It reads
your commits, issues, releases, and README, and produces a site that tells the
project's story to visitors who will never read the code. The site lives in
`/docs` inside the same repo, deploys to GitHub Pages, and updates on a daily
schedule through Claude Code Routines.

## Who it's for

A solo maintainer or small team whose project deserves a cleaner introduction
than a README. Docent is useful when people arrive from a search result or a
shared link and want a direct answer to "what is this and should I care" —
currently getting a wall of markdown instead.

Docent is not a replacement for API documentation tools like Docusaurus or
MkDocs. Those describe how a library works. Docent describes what the project
*is*: the pitch, the current status, recent activity. For visitors who might
never run the code.

## How it works

Two install commands bring the skill into any Claude Code session. One
conversation sets up the site: Docent reads your repo for design signals,
scaffolds an Astro site under `/docs`, generates the initial content — overview,
status page, changelog, inaugural journal post — and opens a pull request.

After merging, a daily Routine keeps things current. Each morning it checks
what's stale: is the status page out of date? Has enough shipped to be worth
a journal post? It produces a PR with whatever combination makes sense —
content refresh, new journal post, both, or nothing. Nothing goes live without
a pull request.

The generated site includes five sections:

- **Overview** — an explanation of what the project is and who it's for
- **Journal** — posts summarizing recent activity on a configurable cadence
- **Status** — open issues grouped and summarized, known bugs, work in progress
- **Changelog** — human-readable release notes derived from tags and merged PRs
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues

The generated content lives in `/docs/content/` as structured MDX and JSON.
An Astro template in `/docs/src/` renders it. Docent writes the content; you
own the presentation.

## Getting started

Docent is distributed as a Claude Code plugin. Install it in any Claude Code
session inside your target repo, then say: **"set up Docent for this repo."**
See the [README](https://github.com/calumjs/docent) for the full install steps,
or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the
design.
