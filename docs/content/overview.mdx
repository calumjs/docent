Docent is a Claude Code plugin that generates and maintains a public-facing website for any GitHub repository. Install it once, say "set up Docent for this repo," and it scaffolds a static Astro site under `/docs`, generates initial content from the README, issues, and commit history, and opens a pull request. After that, a daily Routine keeps the site current — deciding each morning whether to refresh the status page, write a new journal post, or both, based on what's changed since the last run.

## Who it's for

Any maintainer or small team whose project gets visitors from search or a shared link, but has nothing to show them beyond a README. Docent fills the gap between "a wall of markdown that contributors know how to read" and "a page that tells a curious stranger what the project is."

The most direct use case: someone clicks a link from a blog post, Hacker News, or a dependency graph, and lands on a page that explains what the project does, what's been shipping, what's broken, and what's coming — without having to clone the repo or parse a commit log.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far — for visitors who might never read the code.

## How it works

Two install commands add the skill to any Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, picks a visual style from four presets, scaffolds the Astro template under `/docs`, generates the first round of content, and opens a pull request.

After merging, GitHub Pages serves the site automatically. A daily Routine — scheduled via Claude Code's `/schedule` command — runs `update` mode each morning. Update mode is adaptive: it compares source anchors embedded in each generated file against the current repo state, decides what's stale, optionally writes a journal post if enough has happened, and opens a PR with whatever it produced. If nothing changed, it exits silently.

Docent has five modes:

- **`init`** — scaffolds the site and writes the first round of content.
- **`update`** — the daily routine: refreshes what's stale, optionally writes a journal post.
- **`digest`** — writes a journal post on demand ("Docent, write a post about the auth refactor").
- **`release`** — turns a new tag into a changelog entry.
- **`triage`** — drafts suggestions for newly opened issues.

Generated content lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are owned separately: Docent writes content; you own the presentation.

## Getting started

Docent is distributed as a Claude Code plugin. In any Claude Code session inside your target repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **"set up Docent for this repo."** The full install steps and manual post-merge actions (enabling GitHub Pages and scheduling the Routine) are in the [README](https://github.com/calumjs/docent).
