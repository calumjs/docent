Docent is a Claude Code plugin that reads a GitHub repository — its commits, issues, releases, and README — and writes a static website that tells the project's story to visitors who might never look at the code.

The site lives under `/docs` in the same repository and deploys to GitHub Pages. There is no hosted service, no API key to provision, and no backend to run. Inference happens through your Claude Code subscription via a daily Routine.

## Who it's for

A maintainer or small team with a project worth explaining to outsiders. The common situation Docent addresses: someone finds the repo via a link or search result, looks at the README, and can't quickly tell whether the project is relevant to them, still maintained, or how to get started.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the recent history — for people who don't have time to read the code.

## What the site includes

- **Overview** — an AI-written explanation of what the project is and who it's for, refreshed when the README changes or every 90 days
- **Journal** — posts summarizing recent activity on a weekly cadence, written when there's something coherent to say and skipped when there isn't
- **Status** — open issues grouped and summarized, with excluded-label filtering
- **Changelog** — human-readable release notes derived from tags and commit ranges
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab

## How it works

Two install commands add the plugin to any Claude Code session. From there, one conversation scaffolds the site: Docent asks about tone and cadence, reads the repo for design signals, sets up an Astro site under `/docs`, generates the initial content, and opens a pull request.

After the PR merges, a single Routine keeps everything current. Each morning it checks whether the status page is stale, whether the overview needs a refresh, and whether enough has happened to warrant a journal post — then produces a PR with whatever combination makes sense, or nothing if nothing changed.

Nothing goes live without a pull request.

## Getting started

Install the plugin into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent asks a few questions and handles the rest. See the [README](https://github.com/calumjs/docent) for full install steps, or the [SPEC](https://github.com/calumjs/docent/blob/master/SPEC.md) for the technical design.
