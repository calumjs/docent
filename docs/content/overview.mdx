Docent is a Claude Code plugin that turns a GitHub repository into a public-facing static website. It reads your commits, issues, releases, and README, and produces a small site that answers the question visitors actually ask: what is this, and should I care?

## Who it's for

A solo maintainer or a small team with a project that gets traffic from search or links — people who aren't already contributors and won't read the README. Docent is for when a wall of markdown isn't a useful first impression.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the recent history — for visitors who might never read the code.

## How it works

Docent ships as a Claude Code plugin. Two install commands bring the skill into any session. From there, one instruction to Claude Code sets up the site: the skill asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. The same Routine checks whether the status page has drifted from the actual issue set, whether enough activity has accumulated for a journal post, and writes whichever — or neither. Nothing goes live without a pull request.

The site has five pages:

- **Overview** — an AI-written explanation of what the project is and who it's for
- **Journal** — plain-language summaries of recent activity, on a configurable cadence
- **Status** — open issues grouped by theme, with a short description of each group
- **Changelog** — human-readable release notes derived from tags and merged PRs
- **Report a bug / Request a feature** — forms that open pre-filled GitHub issues in a new tab

No hosted service, no API keys, no backend. Inference runs through your Claude Code subscription. Forms submit by opening pre-filled GitHub issues.

## Getting started

Install the plugin in any Claude Code session inside your repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

The skill handles the rest. See the [README](https://github.com/calumjs/docent) for the full setup steps.
