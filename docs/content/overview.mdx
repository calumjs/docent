Docent turns a GitHub repository into a public-facing static website. It reads the repo — README, commits, issues, releases — and writes content that explains what the project is, what has been shipping, and what's open. The site lives in `/docs`, deploys to GitHub Pages via a bundled workflow, and stays current through a daily Claude Code Routine.

## Who it's for

A repository's README serves people who already know the project exists. It answers "how do I use this" more than "should I care about this." Visitors arriving from a search result or a shared link often need something different: a plain description of what the project does, a sense of whether it's active, a way to file a bug without reading the contributing guide.

Docent is for the maintainer or small team with a project worth sharing, whose README was written for contributors. The practical case: you want a site that explains the project to everyone else — without maintaining it manually.

## How it works

Two install commands bring Docent into a Claude Code session. One conversation sets up the site. Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the content current. Each run, the Routine decides whether to refresh the status page, write a journal post, or both — based on what's happened since the last run. Nothing goes live without a pull request.

The generated content lives in `/docs/content/` as structured MDX and JSON. An Astro template in `/docs/src/` renders it. Docent writes the content; the template is yours to modify.

Docent has five modes, each a procedure the skill runs when you ask for it:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes the status page and overview as issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

## Getting started

In any Claude Code session inside your repo:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **set up Docent for this repo**

Docent walks through the rest. Two steps after merging the init PR: enable GitHub Pages via Actions, and set up the daily Routine with `/schedule`. The [README](https://github.com/calumjs/docent) has the full steps.
