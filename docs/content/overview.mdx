Docent reads a GitHub repository — commits, issues, releases, README — and writes a static site that describes the project to people who didn't write it. The site deploys to GitHub Pages from a `/docs` folder inside the same repo, updates on a schedule using your Claude Code subscription, and requires no hosted service, no API keys, and no backend to maintain.

## Who it's for

Most repositories are navigable by their authors and opaque to everyone else. A good README helps, but it's written for contributors: it assumes familiarity, uses project-internal terms, and puts install instructions where the pitch should be.

Docent writes for the other audience — someone who found the project through a search result or a link and wants to know what it is and whether it's worth their time. That visitor gets:

- An **overview** that explains the project in plain language
- A **journal** that summarizes what's been shipping, on a configurable cadence
- A **status page** that shows open issues grouped by theme
- A **changelog** derived from git tags and merged PRs
- **Bug and feature forms** that open pre-filled GitHub issues in a new tab — no accounts required, no third-party services

## How it works

Docent is a Claude Code plugin. Installing it adds a skill that Claude Code uses when you ask it to "set up Docent" or "write a journal post about X." The skill reads the repo and writes structured MDX and JSON into `/docs/content/`. An Astro template in `/docs/src/` renders that content into pages.

The generated content and the Astro template are owned separately: Docent writes the content, you own the presentation. After setup, a daily Routine handles ongoing updates. Each run checks whether the overview, status page, or changelog has drifted from the current repo state, decides whether there's been enough activity to write a journal post, and opens a pull request with whatever combination makes sense. Nothing goes live without a pull request.

Docent has five modes:

- **`init`** scaffolds the `/docs` site and writes the first round of content.
- **`update`** refreshes the status page, overview, and changelog as things change.
- **`digest`** writes a journal post summarizing recent activity, on demand or on schedule.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts suggestions for new issues, without touching them automatically.

## Getting started

[See the README for install steps](https://github.com/calumjs/docent). The short version: two plugin commands, then tell Claude Code to set up Docent. It walks through tone, cadence, and design; generates the first content; and opens a pull request.

After merging, enable GitHub Pages with Actions as the source and set up the daily Routine — both covered in the README.
