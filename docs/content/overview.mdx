Docent converts a GitHub repository into a public-facing static website. It reads commits, issues, releases, and the README, then writes a small site that answers the questions first-time visitors actually ask: what is this, who is it for, and what has been happening.

## Who it's for

A solo maintainer or a small team with a project that deserves a better introduction than a README. Docent is useful when people arrive from search or a link and want a plain-language answer to "what is this" — and currently get a wall of markdown.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current state, the story so far, for visitors who may never read the code.

## How it works

Two install commands add the skill to a Claude Code session. One conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging, a daily Routine keeps the site current. The Routine decides on each run whether to refresh the status page, write a journal post, both, or nothing — based on what has actually happened in the repo since the last run. Nothing goes live without a pull request.

The site contains five sections:

- **Overview** — a written description of what the project is and who it's for.
- **Journal** — posts summarizing recent activity, written automatically on a configurable cadence.
- **Status** — open issues grouped and summarized, updated from the GitHub issue tracker.
- **Changelog** — release notes derived from tags and merged PRs.
- **Bug / Feature forms** — forms that open pre-filled GitHub issues when submitted.

Docent has five modes, each a self-contained procedure:

- **`init`** scaffolds the `/docs` site and writes the first content.
- **`update`** refreshes status, overview, and changelog as the repo changes.
- **`digest`** writes a journal post summarizing a period of activity.
- **`release`** turns a new tag into a changelog entry.
- **`triage`** drafts labels and responses for new issues, without touching them automatically.

The generated content lives in `/docs/content/` as MDX and JSON. An Astro site template in `/docs/src/` renders it. Docent writes the content; you own the presentation.

## Getting started

Install the skill into your repo, then open Claude Code and say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
