Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, releases, and README, and generates a small site that answers the question every first-time visitor asks: what is this project, and why should I care?

## Who it's for

A solo maintainer or small team with a project that deserves more than a wall of Markdown. Docent is useful when people arrive from a search result or a shared link and need a clear, human-readable introduction — not a technical README aimed at contributors.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the status, the story so far.

## What gets built

After setup, the site includes:

- **Overview** — an AI-written explanation of the project, derived from the README.
- **Journal** — posts summarizing recent activity on a configurable cadence.
- **Status** — open issues grouped and summarized, with bugs and in-progress work separated.
- **Changelog** — release notes derived from git tags and merged PRs.
- **Bug report / Feature request** — forms that open pre-filled GitHub issues.

The site lives under `/docs` in the same repository and deploys to GitHub Pages. No hosted service, no API keys, no backend required.

## How it works

Docent is distributed as a Claude Code plugin. Two install commands bring it into any Claude Code session, and one conversation sets up the site: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request.

After merging the PR, a daily Routine keeps the site current. The Routine decides on each run whether to refresh the status page, write a journal post, both, or nothing — based on what's happened in the repo since the last run. Content goes live only through pull requests; nothing publishes automatically.

Docent has five modes: `init` for first-time setup, `update` for the daily refresh, `digest` for on-demand journal posts, `release` for new tags, and `triage` for issue review suggestions.

## Getting started

Install the plugin and run `init` in Claude Code:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say: **"set up Docent for this repo."**

The full steps — including enabling GitHub Pages and setting up the Routine — are in the [README](https://github.com/calumjs/docent).
