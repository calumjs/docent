Docent turns a GitHub repository into a public-facing static website. It reads the repo's commits, issues, and releases, and writes a small site that explains what the project is, what's been shipping, and what's currently open. The site lives under `/docs` in your own repo and deploys to GitHub Pages. There is no hosted service, no backend, and no API keys beyond your Claude Code subscription.

## Who it's for

A solo developer or small team whose project deserves a better public introduction than a README. Docent is useful when people arrive from search or a shared link and want a plain answer to "what is this and should I care" — not a wall of Markdown written for contributors, not visitors.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the recent history, the open issues — for people who may never read the code.

## What the site contains

After installation, Docent scaffolds a live site at `username.github.io/project` with:

- **Overview** — a plain-language explanation of the project, generated from the README
- **Journal** — posts summarizing recent activity, written on a configurable cadence
- **Status** — open issues grouped and summarized by the kind of work they represent
- **Changelog** — release notes derived from tags and merged pull requests
- **Bug report / Feature request** — forms that open pre-filled GitHub issues in a new tab

## How it works

Docent is a Claude Code plugin. Two commands bring it into any Claude Code session:

```
/plugin marketplace add calumjs/docent
/plugin install docent@docent
```

Then say **"set up Docent for this repo"**. The skill asks a few questions — tone, cadence, whether you have a custom domain — reads the repo for design signals, picks one of four visual styles, scaffolds the Astro site under `/docs`, generates the initial content, and opens a pull request. After you merge, one more step: enable GitHub Pages and set up the daily Routine.

The Routine runs once a day. It checks whether the README changed (overview refresh), whether the open issue set changed (status refresh), and whether enough has happened to write a journal post. It opens a pull request when something needs updating, and does nothing when everything is current.

You can also invoke Docent manually for specific tasks: generating release notes from a tag, writing a post about a particular feature, or triaging new issues.
