Docent is a Claude Code plugin that generates a public-facing static website from a GitHub repository. It reads commits, issues, releases, and the README, then writes content that tells the project's story to non-developer visitors — what it is, what's shipped, what's open.

The site lives inside the repo under `/docs` and deploys to GitHub Pages. No hosted service, no API keys, no backend. Content stays current through a scheduled Claude Code Routine that runs daily and decides, based on what's changed, whether to update the status page, write a journal post, both, or nothing.

## Who it's for

A solo maintainer or a small team with a project that deserves a better first impression than a README. When someone arrives from search or a link and wants to know whether to care — and currently gets a wall of markdown — Docent gives them something to read instead.

Docent is not a replacement for API documentation tools like Docusaurus or MkDocs. Those describe how a library works. Docent describes what a project *is*: the pitch, the current status, the history.

## How it works

Two install commands bring the plugin into any Claude Code session. From there, a single conversation runs the `init` mode: Docent asks about tone and cadence, reads the repo for design signals, scaffolds an Astro site under `/docs`, generates the initial content, and opens a pull request. Nothing lands on `master` without a human merge.

After the PR merges, a daily Routine keeps the site current automatically. The same Routine checks whether anything has drifted — issues resolved, README updated, new tags pushed — and regenerates only what's stale.

Five modes cover the full lifecycle:

- **`init`** sets up the site and generates the first round of content.
- **`update`** refreshes the status page and overview when issues and the README change.
- **`digest`** writes a journal post summarizing recent activity.
- **`release`** converts a new tag into a changelog entry.
- **`triage`** drafts suggestions for incoming issues, without touching them.

Generated content — overview, journal posts, status groupings, changelog — lives in `/docs/content/` as MDX and JSON. An Astro template in `/docs/src/` renders it. The two halves are separately owned: Docent writes the content; you own the presentation.

## Getting started

Install the plugin in any Claude Code session inside your repo, then say:

```
set up Docent for this repo
```

Docent walks through the rest. See the [README](https://github.com/calumjs/docent) for full install steps, or [SPEC.md](https://github.com/calumjs/docent/blob/master/SPEC.md) for the design.
